# Canonical review guidance

Use the canonical repository steering:

- [Shared steering](../docs/agent/STEERING/): `docs/agent/STEERING/`.
- [Frontend steering](../frontend/docs/agent/STEERING/): `frontend/docs/agent/STEERING/`.
- [Backend steering](../backend/docs/agent/STEERING/): `backend/docs/agent/STEERING/`.

Select applicable domains and rules by the review action and changed paths. Use domain names, filenames, and targeted searches. Read applicable rules and necessary related rules in full before reviewing. Shared and service rules are mandatory within their scopes. Service rules do not silently override shared rules. Do not preload unrelated domains or entire trees. Reassess when the review scope changes.

These links are retrieval instructions, not automatic file inclusion. If a rule cannot be accessed, report the gap. Do not invent its content.
